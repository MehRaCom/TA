Task Memory fairness across days

Makes the random assignment remember previous days. Each day, the last assignment the bot posted to Telegram counts as that day's final one. Everyone then starts today with a load built from what they did on those days, so whoever carried more recently gets fewer tasks. Every behavior below is its own switch. History is recorded all the time, even while this is off, so it's ready when you turn it on.

3 · Fairness method

What is stored is plain fact (who was present, which tasks were on the table, their weights, who got what) and never depends on the method. The method only decides how those facts become each person's starting load today, so you can switch whenever you like and the whole past is used immediately. Meters come from a simulated 300-day replay of a 5-person team (30 runs, each method with its own sensible settings); more dots is better. The README explains each method in depth.

Use a different method on certain weekdays

Leave a day on "default" to use the method picked above. Each day's own method is part of the duplicate check, so changing it lets a new assignment be made that day.
